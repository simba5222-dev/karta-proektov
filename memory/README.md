# Память по карте

Сюда `memory-sync.sh` в конце сессии зеркалит живую память Claude
(`~/.claude/projects/-home-claude-karta/memory`), чтобы уроки пережили потерю сервера:
код в git, а память до этого жила только на диске машины.

Файлы кладутся и стейджатся, но не коммитятся — коммит остаётся явным действием.
Записи с секретами в индекс не попадают: перед стейджем идёт скан.

Пока живой памяти по этому проекту нет, каталог пустой — это нормально.
